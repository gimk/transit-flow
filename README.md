# Transit Flow

A 2D top-down street simulation, written in Rust and Bevy.

The setting is an urban designer in Paris. Each level is one real intersection. The buildings and the street width are fixed. You share the space between cars, cyclists and pedestrians: lanes, crossings, signals, speed limits, kerbs, planters and green areas. Then you start the run and watch what happens.

Annoyance, conflicts and injuries cost points. Free space, rest and green areas give a bonus.

## Status

**Very much a work in progress.** It is a simulation first, not a game yet. Many things are missing, unfinished or will change. Expect bugs and rough art.
